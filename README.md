# 教师行为标签制作工具

本仓库当前包含两个可以独立安装、测试和运行的 FastAPI 项目：

- `make_label`：从课堂视频抽帧，结合 ImageDetect 和 VLM 制作教师行为 YOLO 标签。
- `app`：在本地浏览、修改、拒收和复核已生成的 YOLO 标签。

两个项目使用各自的 Python 环境和依赖文件。请进入对应目录后运行，避免在同一 Python 进程中同时导入两个名为 `app` 的包。

真实课堂图片、数据集、临时帧、服务日志、原始响应和包含凭据的 `config.toml` 不属于源码仓库，均由根级 `.gitignore` 排除。

具体安装和启动方式见各子项目 README。
